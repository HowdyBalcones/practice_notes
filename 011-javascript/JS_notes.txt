Types
   - Primitive Types: numbers, strings, booleans, null, undefined, Symbol (ES6)
   - Object Types: Everything that is not a primitive type.
   
   - Boolean ch. 3.4, 4.10
   + True or False
   + Generally the result of a comparison
   + Any javascript value can be converted to a boolean
   These will typically evaluate to false: 
   undefined, null, 0, -0, NaN, "" 
   + Every other value will generally convert to true. This is truthy and falsey. 
   

   - Null, undefined
   + null implies an absence of value, it is the only object of its class. 
   + also NULL, nil, or None
   + undefined implies that a variable has not been initialized, or that a given value no longer exists. 
   Also the return value of functions that don't explicitly return a value
   and the value of function parameters where no value is passed in. 
   + == considers null and undefined equivalent, strict equality or === distinguishes between the two
   +

   - Global Object ch. 3.7
   + Properties of this object are available to a Javascript program. 
   + Whenever the JS interpreter starts, or when a browser loads a new page, it creates a new global object
   + It defines: 
   Global constants - undefined, Infinity, NaN
   Global functions - isNaN(), parseInt(), eval()
   Constructor functions - Date(), RegExp(), String(), Object(), Array()

   - Immutability and Mutability ch. 3.8
   + Primitives are Immutable, it doesn't make much sense to alter their value.  
   When they are "altered" by some function or method, a new value is returned without changing the original. 
   + Objects are different from primitives. They are mutable, their values can altered directly. 
   + Two objects are not equal, even if they have the same properties and values. 
   This also holds true for arrays, even if they are the same length and contain the same values.  
   + Mutability implies that you are referring to a discrete spot in memory, that if two different variables point to the same place
   altering that memory will change both variables. 
   + Shallow and Deep copies. A shallow copy will be altered if the point of reference is altered. A deep copy is entirely
   independent from the source. I think that means it creates a separate distinct space in memory. 
   + If you want to compare two different objects for equality, you have to test their individual elements. 
   
   - Type Conversions ch. 3.9
   + JS will liberally convert one type into another. 
   Basically anything can become a string.
   Numeric conversions are trickier, but notably a string such as "2" * "2" will return 4 
   Any type can convert to a boolean
   null and false will convert to 0, true will convert to 1, like in unix

   Number("4");
   String(false);

   - Destructuring ch. 3.10.3
   + the value of the right side of = is an array or object, and the left side is 1 or more variables that mimics the right side
   When assignment occurs, one or more of the values are extracted (destructured) from the values on the right side and 
   initialized into the variables on the left side. 
   + This can also reinitialize variables. 
   + the variables on the left do not need to match the values on the right explicitly 
   + commas can be used in the variables to skip given values on the right
   + you can pass the remaining values on the right to a single variable on the left using ...variable notation
   + This destructuring syntax can be used on objects using an iterable object ch. 12
   + any object that can be used in a for/of loop ch. 5.4.4 can also be destructured

   - Numbers
   + 64 bit floating point, or a double in C++, Java, etc
   + Recognizes hexadecimal values: 0x or 0X followed by 1-9 and/or A-F (a-f)
   + allows scientific notation: [digits][.digits][(E|e)[(+|-)]digits]
   6.02e23
   1.4738223E-32
   + you can use underscores to separate long number sequences for easier reabability. 
   + infinity and -infinity are special numbers for when a float exceeds max or min value
   + Number object
   Number.parseInt() // same as global parseInt() func
   Number.parseFloat() // = global parseFloat() func
   Number.isNaN(x) // returns bool on x === NaN
   Number.isFinite(x) // is x a number and finite
   Number.isInteger(x) // is x an int
   Number.isSafeInteger(x) // is x an integer -(2**53) < x < 2**53
   Number.MIN_SAFE_INTEGER 
   Number.MAX_SAFE_INTEGER
   Number.EPSILON // smallest difference between numbers
   + NaN: will never have equality with another number
   This means x === NaN is invalid. Use Number.isNaN(x) or x !== x
   + Because of binary, fractions are not always rounded the same way. 
   + BigInt can represent more numbers than the standard Number, but they can only be integers. 
   written as a string of digits followed by a lowercase n
   they can also be in base 2, 6, 8
   1234n
   0b111111n
   0o7777n
   0x8000000000000n

   - Text: Strings ch. 3.3
   + an immutable ordered sequence of 16-bit values, each usually a Unicode character. 
   + Length of a string is the number of 16-bit values it contains. 
   + 0 indexed
   + Empty strings have a length of 0
   + There is no char in JS. use a string with the len of 1 (a single 16 sequence)
   + Most characters will be included in the "multi-lingual plane" of Unicode. EG, they fit in a 16-bit sequence.
   + When a Unicode character does not fit in a 16-bit sequence, it is expanded into a surrogate-pair (two appended 16-bit seq.)
   + String literals are strings contained within "" or ''. Don't mix them, like "' or '"
   + Template literals are enclosed in `` and allow embedding arbitrary expressions into a formatted string
   Refer to ch. 3.3.4
      - Will always convert the returned values of any included expression into a string
      - Tagged template literals are new to me, check example on ch. 14.5 and review with MDN
      Apparently useful for escaping SQL or HTML 
      - They work by placing a function name in front of the backticks. The result of the template literal is then 
      passed to the given function. 
      
   
   + You can break a single string literal onto multiple lines with the use of \
   + Has escape characters, like Bash
   \0 // the NUL character (\u0000)
   \b // Backspace (\u0008)
   \t // Horizontal tab (\u009)
   \n // Newline (\u000A)
   \v // Vertical tab (\b\u000B)
   \f // Form feed (\u000C)
   \r // Carriage return (\u000D)
   \" // Double quote (\u0022)
   \' // Apostrophe or single quote (\u0027)
   \\ // Backslash (\u0027)
   \xnn // Unicode character specified by two hexadecimal digits nn
   \xnnnn // Unicode character specified by the four hexadecimal digits
   \u{n} // Above, specified by the codepoint n, where n is one to six hexadecimal digits between 0 and 10FFFF
   If the \ is used before any other character, it is effectively ignored by JS
   + Concatenation of strings: "What" + "String?"
   + Equality operators compare the exact sequence of the 16-bit values between two strings
   see ch. 11.7.3 for additional string comparison technique

Control Structures
   - let x of array
   function sum(array) {
      let sum = 0;
      for (let x of array) {
         sum += x;
      }
      return sum;
   } // sum the elements of an array and return total
   
   - while loop
   function factorial(n) {
      let product = 1;
      while (n > 1) {
         product *= n;
         n--;
      }
      return product;
   }

   - for loop
   function factorial(n) {
      let product = 1;
      for (let i = 2; i <= n; ++i) {
         product *= i;
      }
      return product;
   }

Lexical Structure
   - JS is case senstive
   - Comments: /* Multiline */ and // Single line
   - Literals: data value that appears directly in the program EG 12, 1.2, "hello world", true, false, etc
   - Identifiers: constants, variables, properties, functions, classes, labels for certain loops. 
   Must begin with a letter, an underscore, or a dollar sign. 
   - Reserved words: These are part of the JS langauge by default
   as, async, await
   break
   case, catch, class, const, continue
   debugger, default, delete, do
   else, export, extends
   false, finally, for, from, function
   get
   if, import, in, instanceof
   let
   new, null
   of
   return
   set, static, super, switch
   target, this, throw, true, try, typeof
   var, void
   while, with
   yield
   - Unicode: JS uses Unicode characters except emojis. This means JS in any language should be valid. 
   + Escape sequences: for older systems that don't have full Unicode support. 
   caf\u00e9 or caf\u{E9} : the \u followed by a 4 digit hexadecimal number
   + While it is standard to use ASCII characters only, be aware that Unicode has multiple ways to encode the same characters. 
   So there could be an instance where the same Idenfitifier is being interpreted as two separate values. 
   - Optional semicolons: 
   Just use semicolons when you finish a statement. Don't understand the need to get into the weeds on this issue. 
   Worth noting: Arrow syntax; the arrow must be on the same line as the parameters for the function.
