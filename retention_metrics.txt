>> SERVER ORGANIZATION

-- There are various servers hosted at Select. The graphic designer uses:
	- Graphics -- primary storage of all Graphical assets. Packaging artworks, product photos, branding assets, etc.
	- Labels -- storage for production labels. Case labels, sleeve labels, warehouse labels. 
	- Marketing -- Marketing assets for Sales. There is a duplicate of the WEB images in /003-Product_Images/001-allPhotos/WEB
	Whenever you update photos from the MASTER list into WEB, you have to update the marketing photos as well. 
	- Shared -- there is a graphics folder in shared that is for anything that needs to be shared that doesn't go in the previous
	three folders.

-- Naming conventions and folders
	- Graphics Server === Select III
	- Folders are prefixed with numbers so they appear in a consistent order. 

	- Creating long trees of folders makes things difficult to find. If you can store many things of the same type in one place, 
	it ends up being more efficient to simply apply a naming convention to files rather than create many separate folders. 
	Keeping to this rule will make organizing simpler. The times where we break this rule is when isolating files is important. 
	
	001-Components
	- Production Artworks are in 001-Components - These are artworks for every individual package form, often called "paper". 
	They are organized by the "product family", which is usually a common product that goes into the various package forms.
	
		- Inside a component folder: 	
		+ Various folders organized by COMPONENT NUMBER, that contain the folders for

		000-Staging
		+ Artworks that are in production are kept here. "In Production" just means we are making it for the first
		time. After proofing, they are moved into their given component folders. 
		+ Folders here are for keeping various projects organized.

			- Once the artwork has been sent to approval, move that artwork to its pending folder.

	- Refer to the Approval flow chart
		1 Order for changes comes through
		2 Update Job Board with latest order
		3 Update pending with template using Graphics Server naming conventions
		4 Verify REV Code, all three UPCs, Dates, Specs of item, Dieline Number, Reference Graphic
		5 Place these onto the pending artwork or into the reference graphics folder in server
		6 Complete changes for the given update
