selectors: https://developer.mozilla.org/en-US/docs/Learn/CSS/Building_blocks/Selectors

/*This is a comment in CSS*/

	- Selector = the HTML element name at the start of the ruleset
	- Declarations = color:red;
	- Properties = options to style HTML elements. You choose which property is affected by the rule.
	- Property value = to the right of the property value. 
	- a colon : separates properties from their values
	- a semi colon ; separates declarations

basic declaration
	p {
		color: red;
	}

multi declaration
	p, li, h1 {
		color: red;
	}

	Types of selectors
	- Element Selector - all HTML elements of the same type - p selects <p>
	- ID selector - element on the page with a specific ID, should be unique - #my-id selects <p id="my-id"> or <a id="my-id">
	- Class Selector - element on the page with a specific class, can share multiple elements - 
	.my-class selects <p class="my-class"> 
	- Attribute Selector - elements on the page with a specific attribute - img[src] selects <img src="myimage.png"> but not <img>
	- Pseudo Class selector - specified elements, but only when they are in a specific state - a:hover selects a while hovering

CSS is a box language. The visualisation of elements on the page is as layers of different boxes. 
	- padding
	- border
	- margin
		- width, back-ground-color, color, text-shadow, display
