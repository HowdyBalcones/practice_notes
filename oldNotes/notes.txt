Meta-Characters
1. Wildcards (*, ?, []): Used for pattern matching and globbing. * represents any sequence of characters, ? represents a single character, and [] represents a range of characters.

2. Redirectors (>, <, >>, |): Used for input/output redirection and piping. > redirects output to a file, < redirects input from a file, >> appends output to a file, and | pipes the output of one command to the input of another.

3. Quotes (', "): Used to quote and preserve the literal meaning of characters, preventing their interpretation as meta-characters. Single quotes (') preserve the exact characters enclosed within them, while double quotes (") allow for variable expansion and command substitution.

4. Escape character (\): Used to escape or quote a meta-character, treating it as a literal character. For example, \$ escapes the $ character to prevent variable expansion.

5. Command substitution allows for capturing the output of a command and use it as input or assign it to a variable. ($(command) or command): Used to substitute the output of a command into a command or expression.

These are generally referred to as I/O Redirection, apparently it's one of the most powerful aspects of bash scripting and why it's still in use.
	- The symbols for redirection are
	- > < | >> << 
	- If a program writes to stdout, use > to make it write to another file or program instead
	- You can send the output from one program to another with a pipe, or | symbol
	- If a program reads from stdinput, redirect the input from a file to the program with < 
	- >> appends to a file rather than overwriting it. Overwriting with I/O in Unix is called clobbering a file.

Summing UP - Nomenclature - 
	- Regex, shorthand for Regular Expressions
	- Matching - egrep 'a' doesn't match the word 'cat' it matches the 'a' in 'cat'
	- Metacharacter/Metasequence - depends on where in a regex it's used. * is a metacharacter, in [*] is taken as a literal character. Understanding this 
	bit will take comprehension of the vocab and the ability to think in terms of the expression itself. 
	- Flavor - There are different rules and structures for regex depending on the context, such as between programming languages, between different programs,	  and between different versions of the same program. egrep is apparently especially egregious in this way. 
	- Subexpression - Simply, refers to a smaller part of a larger expression. Often used to mean something contained within () or alternations separated by |	  Technically speaking, every literal character is a subexpression of its main expression. This is why metacharacters such as * always refer to 
	the smallest subexpression possible, and why the () and [] become relevant when applying prefixes or other characters.
	- Characters - depends on your encoding, this was covered a bit in the complete intro to Linux
	- . - matches any single character
	- [] - character class - matches any one character listed
	- [^] - matches any one character not listed, is a positive statement
	- \char - matches the literal character unless the character is not a metacharacter in which case it might become a special character depending on
	the program and version of regex you are using. 
	- ? - question - One match is allowed, but is optional
	- * - star - 0 to any amount of matches are allowed, all are optional
	- + - plus - At least one is required, additional are optional
	- {min,max} - specified range - min required, max allowed
	- ^ - caret - Matches position at the start of the line
	- $ - dollar - Matches position at the end of the line
	- \< - word boundary - Matches position at the start of a word
	- \> - matches position at the end of the word
	- | - alternation - Matches either expression it separates
	- () - parenthesis - Limits scope of alternation, provides grouping for quantifiers (?,*,+, {min,max}), and captures backreferences
	- \1 \2 - backreference - Matches text previously matched in order sets of parenthesis, (1)(2)\1\2 for instance
- Not all egreps are the same! Read documentation! Become the documentation!
- Parenthesis - Contrain alternation, grouping, and capturing 
- character classes are special and have their own set of metacharacters and rules, distinct from the regex language
- Alternation and character classes are different, though the have functional overlap
- A negated character is still a positive assertion, as in it must still match a character in order to return true. 
- Use -i option for egrep and other programs to hopefully implement case insensitivity
- Three types of escaped items
	- \metacharacter to change it into a literal character
	- \certain literals can become program specific options, such as \n (newline)
	- \any other character that doesn't fall into these categories has the \ignored
- [\] turns \ into a literal character
- ? items don't need to actually match any character to match succesfully, they are optional

Data Structures - Applications

Trees
	- Like a file system, hierarchal storage system
	- rapid information retrieval, organizational structure
		- used in binary search trees, achieves faster search results
		- used in heaps, often applied in queues to establish priority, also heap sort
		- used in syntax trees, determines the order of operations in mathematical expressions for example
	- Summary - It seems any system that requires a hierarchal order to the information of the system could potentially benefit from a tree structure, and is likely using
	something like a tree structure already. There are computational benefits to using tree structures, reduction in the amount of processing by eliminating portions of 
	the given data, ensuring rules of a stated hierarchy are applied evenly across given data, establishing priority in data
Singly-Linked List 
	- Nodes containing some data, with a pointer or link to the next node in the list. Ends with a null statement. Each node has 1 pointer, only to the next node. 
	- The main benefit is the enforced order of the structure, you must start at the beginning and procede down the list in the order given by the pointers. This 
	simplicity is useful in building out various other data structures.	
		- Used to build stacks and queues
		- A queue has a FIFO structure, when we want to add something to the queue it's added to the tail of list, the front of the queue (priority )is the head. 
		- Used to create hash tables
		- used in memory management
		- used in browser history simple
		- access time is linear compared to a tree
	- Summary - A simple structure that is important for it's flexibility and use in the construction of more complex data structs. It ensures steps are being followed. 
Doubly-Linked List
	- Nodes containing some data, with pointers to the next and the previous node. Both head and tail of list are null. 
		- Used when you need to traverse forwards and backwards in a list of given data points. 
		- Example would be a playlist of songs, where you want to be able to jump forward and backwards between songs. 
		- Example would be the forward and back buttons in a browser. 
		- Used when insertion into the list is neccesary
		- Downsides are, it takes up more space than a singly-linked list because it stores double the amount of pointers. During insertion/deletion, more links 
		will need to be updated.
 		- 
Hash Tables
	- Used to index large amounts of data, in database indexing, compilers, caching, password authentification, and more
	- Maps keys to values in an associative array. If you have a series of item numbers for instance, that map to various kinds of product data, hash tables would assign
	each key value with an index number created through some algorithmic processing of the key value.
	- Key - the value that is being stored and is searched for
	- Index - assigned to each key in the table 
	- Algorithm - used to create the index of the key 
	- Hash table - a key and its associated index number
	- Hash map - a key, its index, and the key values that are associated with the key. 
	- Hash algorithm - Calculation done to the key to retrieve the index of the key, or its address in the table
		- minimizes collisions
		- uniform distrobution
		- easily caluclated
	- Collisions - your algorithm produces different keys with the same index. 
		- open addressing - linear probing - try the next index address until empty slot is found
		- plus 3 rehash - quadratic probing - double hashing 
		- closed addressing - chaining - creating a linked list at the shared index
		- 
	- Load factor - total number of items stored / the size of the array
	- Summary - Hash tables give searchable values index numbers algorithmically so that when information is input the hash function can reference its search table 
	according to a value it knows instantly, based on the algorithm used to index the values.

- Structure & Syntax - 
	- a command is structured: pattern/action, which designates a pattern to match against and an action to run for each match
	- all awk scripts have three stages fundamentally: BEGIN, main input loop, END
	- BEGIN is run once before any input is read
	- main input loop runs on every line of input and stops when there are no more lines
	- END is executed after all input is read
- ~ - 
	- used to test a pattern against a specific field
	- !~ - used to match inverse statement: match everything besides pattern
	- 
- Fields - 
	- NF - This variable controls the number of fields. 
	- $NF - This will select the last field
	- The character that separates fields is called a delimiter
	- operator: $X, as: $0, $1, $2
	-

	- awk will process every line, including blank lines
