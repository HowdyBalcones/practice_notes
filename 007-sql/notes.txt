+ Syntax
	; - always end statements with a semicolon
	CREATE TABLE <table_name> - make a new table
	SELECT - indicates statement is a query
	FROM - specifies the name of the table for the query
	INSERT - insert a new row (record) into a table
	INSERT INTO - clause, adds specified row or rows into a table
	VALUES - clause, identifies the columns the data will be inserted into
	ALTER TABLE - make changes to a table
	ADD COLUMN - add a column when altering specific table(s)
	UPDATE <table> - edit a row in a table
	SET <column> = <value> - change a record on the table, combined with WHERE often
	DELETE FROM <table> - delete something from a given table
	WHERE <record, value> = <value> - indicates which row to target with a given command
	CREATE INDEX <index name>
	ON <table name> (column1, column2, ...)
	AS - returns value under an alias, often used to rename columns for output 
	COUNT
	DISTINCT - only returns unique values
	ROUND
	WHEN
	THEN
	CASE 
	END - closes a case statement 
	AND
	OR
	IS <command, value> - when a condition IS met, or IS returns true 
	NULL
	JOIN - combine multiple tables
    CROSS JOIN - pairs each row from one table with another table, can be constrained with WHERE
    UNION - Stack columns on top of one another, conditions = same num of columns, columns have same types in the same order
	GROUP BY - used with aggregate functions, arranges identical data into groups, after WHERE before ORDER BY, LIMIT
	HAVING - filters groups, similar to WHERE but for groups instead of rows
	ORDER BY - sorts by a given column
	DESC - ordered high to low or Z-A
	ASC - ordered low to high or A-Z
	LIMIT <int> (not always valid syntax depending no RDMS)
	COUNT() - count number of rows
	SUM() - sum values of a column
	MAX() - largest value
	MIN() - smallest value
	AVG() - average the values of a column
	ROUND() - round the values of a column
	
	strftime()
	date()
	time()
	datetime()
	julianday()
	unixepoch()
+ Concepts
    Primary key vs Foreign Key
    - A primary key is a unique identifier for a row in a given table. 
    - When a primary key from a different table is in a given table alongside a primary key, it is known as a foreign key

+ Types
	INTEGER -- +- whole num
	TEXT -- string
	DATE -- date formatted YYYY-MM-DD
	REAL -- decimal, float
	NULL -- missing or unknown value, new columns with no data have this by default
+ Constraints -- invoked after specifying the data types for a column when creating or adjusting a table
	PRIMARY KEY - uniquely identifies rows, attempts to add identical rows with same unique id throws error "constraint violation"
	UNIQUE - records should not contain duplicates in given column
	NOT <value match>  - should not match given value, IE NOT NULL (shouldn't be empty)
	DEFAULT	- columns take additional argument the is assumed value if nothing is provided

+ Wild Cards -- think regex and bash wildcards but with different flavor
	* - all, every match
	_ - any single character
	% - anchor, A% starts with, %A ends  with, %A% begins and ends with	

+ Definitions
- Relational Database
	Database - data stored on a computer.
	Relational Database - Type of database, access data in relation to other pieces of data in said database. Often with tables.
	Rows and Columns - A row is a record, a column is a data type with a specific name
	- name - age - country
	- travis - 23 - America
	- natalie - 34 - Britain
	- rick - 74 - Earth
- Relational Database Management System (RDBMS)
	Create, update, administer a relational database
	- Examples
	MySQL - Used to be open source, now owned by Oracle, industry standard
	PostgreSQL - Open source, similar to MySQL
	Oracle DB - Oracle
	SQL Server - Microsoft
	SQLite - preferred
	- Extensions
	.sqlite = SQLite
	.sql = PostgreSQL
	- Types
	SQLite and PostgreSQL have slightly different types. Recorded as we go below:
