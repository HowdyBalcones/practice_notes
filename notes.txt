Notes 
-- Fishbowl is the key record. Website, Salesforce, future software, will all work on top of Fishbowl. That means if there is something you want changed, do it in Fishbowl first. Fishbowl pushes up to our other software. That software does not push down to Fishbowl until there is a sync.
-- selectcorp.net
-- selectcorporation.net

Fishbowl 
-- Use Customer and Product modules primarily, "Custom" tab for both

How to Login 
Front End -- 
-- employees have user accounts 
   >> Username = Email
   >> password = first time, admin password, otherwise user set password
-- logging into backend will prompt for dual auth
-- it should be sent to your accounts associated email
Back End -- 
-- should be the same process, follow the link and use work email for any credentials
-- here you can view your account as well as others. If a customer needs help log into their account from here. 
   that is under Customers > Edit (drop down) > "Login As"

Sync
-- syncing: if there is something new in Fishbowl, you need to sync the backend for the front end website to know about it. 
   This includes new Accounts, New pricing, new product, new inventory, etc etc. If you are in any way worried data from Fishbowl
   is out of date on the website, push a sync from here. 
   Sync > Status > Clock symbol (drop down)

Approving Customers 
-- Multi Step process
1 - Receive request for account through website
  >> This should be through the orders@selectcorporation.net email -- double check

2 - Receive all paperwork, internal review of account if a fresh lead

3 - If mgmt has approved the account, then we approve their website user application
    >> Customer > Edit (customer account drop down) > SET YOUR SALESPERSON > Approve Customer Account > SET PASSWORD > SAVE >>
    done
4 - Then we grant web access in Fishbowl
    >> Sales > Customer > Custom (tab) > Distributor Portal - Grant Web Access > Dist Portal Prod view set to "Case" > SAVE >>
    done

5 - Move to processing first order

If they already have an account with Select, follow steps 3 - 4. 

How to view available products
-- products are either visible to customers or not. 
   >> There are two places to check. >> Product > Custom > Product View Restrictions 
   >> We've been here before >> Customer > Custom (tab) > Dist Portal Prod View Restrict
   >> These both need to be TRUE before the customer can see anything on the website.  
-- checking what products are visible >> Our Products > All Products >> if you cannot see anything, something is set wrong.
