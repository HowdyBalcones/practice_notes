- Heaps 
    + a binary tree with a maximum and minimum value.
    + min heap - the root is the minimum value of the dataset, every child value is greater than or equal to its parent
    + max heaps - the root is the maximum value of the dataset, every child value is less than or equal to its parent
    + max heaps and min heaps are considered separate structures
    
- Binary Tree
    + has the following properties: 
    Data
    depth value - top level is 1, everything greater than 1 is lower in the tree
    left pointer - points to the left child of the tree, itself a binary tree, and must have data lesser than the root nodes data
    right pointer - points to right child of the tree, itself a binary tree, must have data greater than the root nodes data
    + traversing a binary tree
    Three methods: Preorder, Inorder, Postorder. 
    Preorder - current node, left child node, then right child node
    Inorder - left child node, current node, right child node -- this will give you a sorted list of the tree values
    Postorder - left child node, right child node, current node

    + Requires a sorted data set.

    if match return data
    + if middle < target
    start at step 1 using right half of list
    + if middle > target
    start at steo 1 using left half of list
    // we know this is a logarithmic time complexity without considering the sorting. 
    // you are looking at half as much of a list each time you iterate. 
    + With the sorting, we resort to linear search O(N) speed complexity
    
    + binary search example: 
const binarySearch = (arr, target) => {
  let left = 0;
  let right = arr.length;
  
  while (right > left) {
    const indexToCheck = Math.floor((left + right) / 2);
    const checking = arr[indexToCheck];
    console.log(`indexToCheck equals: ${indexToCheck}`)
  
    if (checking === target) {
      return indexToCheck;
    } else if (target > checking) {
        left = indexToCheck + 1;
    } else {
        right = indexToCheck;
    }
  }
  return null;
} 
- tree data structures
    + has a root, the topmost element of the tree
    + they are structured, pointing down a tree splits. The left split is always less than it's parent, and the right is always
    greater. This structure ensures efficient access to child elements of the root. This is called binary search. 
    + composed of nodes related by reference to other nodes: parent -> child relationship. elements within the child are known
    as leaves.
    + Leaves do not have references to any other nodes; they have no children. 
    + Children are held as references to parent nodes. 
    + Parents may be related to other parents, children, and leaves. 
    + Roots are not held as reference to any other node
    + Use cases: hierarchical information, organizational charts, genealogical trees, computer file systems, HTML elements "DOM", 
    state diagrams, and etc
    + Tree has nodes, nodes are a simple structure with data and a list of children, children are also tree nodes
    + Functions of a tree are adding and removing data, and traversing the tree in two ways: 
    + Depth first
    + Breadth First.

- asymptotic notation
   + Used to understand the total number of instructions a program will require. 
   + Theta, O, and Omega are used to represent N^2
   + Use the most dominant term in the formula, which means the most computationally significant. 
   + Big ol Theta: use when there is only has one case in terms of runtime
   function(n) 
      count = 0
      while N/2 !== 0;
         increment count
         N = N/2;
      return count
   Counting these iterations will give you Asymptotic notation.
   For the above pseudo code, you get Theta log2 N
   + Common runtimes: 
   0(1) - constant run
   0(log N) - logarithmic run
   0(N) - linear run
   0(N log N) - used in sorting
   0(N^2) - polynomial run time
   0(2^N) - exponential run time
   0(N!)  - factorial run time
