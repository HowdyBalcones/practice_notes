- Graphs with Javascript 
   + A data structure to represent data points, or vertices, that are connected by edges.
   + Used in maps where each location is a vertex, each path or road is an edge. 
   + Features: Directed or undirected, weighted or unweighted, vertices, edges
      - Nodes/Vertices: Represent entities within the graph. 
      - Edges: Represent relationships or connections between vertices. 
      - Paths: A series of edges connected by vertices. 
      There can be multiple edges between vertices. 
      - Types of Graph: Directed, Undirected, Weighted, Unweighted, Sparse, Dense, Cyclic, Acyclic
      - Directed & Undirected: 
         * Directed -> edges have a direction. A -> B, where A is connected to B but not neccesarily the inverse.
         * Undirected -> Bidirectional. A <-> B, where both are connected.
      - Weighted & Unweighted:
         * Weighted -> edges have associated weights or costs.
         * Unweighted -> All edges are treated equally, with no weights.
      - Sparse & Dense:
         * Sparse -> Few edges relative to vertices. 
         * Dense -> Many edges relative to vertices. 
      - Disconnected -> no edges between a pair or more of vertices. 
      - Cyclic & Acyclic: 
         * Cyclic -> Contains cycles
         * Acyclic -> Does not contain cycles
   + Cycles: where connecting edges return to the initial vertice
   + Adjacency List: A table. Both columns and rows are the same list of vertices. 
      - to find a connection or relationship, you find the point of connection in the table. 
      - You could show this as a traditional table, a graph, or an adjacency list (an object here).
   + Pseudo Vertex, Edge, Graph classes
   Vertex: Stores any data, maintains a list of connections to other vertices, represented by a list of edges instances.
   Can add and remove edges going to another vertex. 
   Graph: Stores all of its vertices, a list of vertex instances. 
   Knows if the graph itself is directed or undirected.
   Knows if the graph is weighted or unweighted. 
   A graph can add/remove its own vertices. 
   The graph can also add and remove edges between stored vertices.

class Graph {
  constructor(isWeighted = false, isDirected = false) {
    this.vertices = [];
    this.isWeighted = isWeighted;
    this.isDirected = isDirected;
  }

  addVertex(data) {
    const newVertex = new Vertex(data);
    this.vertices.push(newVertex);

    return newVertex;
  }

  removeVertex(vertex) {
    this.vertices = this.vertices.filter(v => v !== vertex);
  }

  addEdge(vertexOne, vertexTwo, weight) {
    const edgeWeight = this.isWeighted ? weight : null;

    if (vertexOne instanceof Vertex && vertexTwo instanceof Vertex) {
      vertexOne.addEdge(vertexTwo, edgeWeight);
    if (!this.isDirected) {
      vertexTwo.addEdge(vertexOne, edgeWeight);
    }
    } else {
      throw new Error('Expected Vertex arguments.');
    }
  }

  removeEdge(vertexOne, vertexTwo) {
    if (vertexOne instanceof Vertex && vertexTwo instanceof Vertex) {
      vertexOne.removeEdge(vertexTwo);
    if (!this.isDirected) {
      vertexTwo.removeEdge(vertexOne);
    }
    } else {
      throw new Error('Expected Vertex arguments.');
    }
  }

  print() {
    this.vertices.forEach(vertex => vertex.print());
  }
}

- Merge Sort
   + Done in two steps: Splitting data into "runs" or smaller components, and then recombining runs into sorted lists.
   + Call sort on the list, which cuts that list in half. Recursively call sort on those two halves, until each 
   list only has a single element. Then begin merging. 
   + While merging single element lists, compare their values. 
   + Return each element list with the smaller element followed by the larger. 
   + Merging larger pre-sorted lists
      - Two lists, left and right. 
      - Final merged list called both. 
      - to merge, iterate through both with a two indices, left_index and right_index
      - left_index and right_index both point to their smallest value at the start
      - Compare left_index with right_index and the smaller of the two is added to both. 
      - Whichever list had the smallest index, check the next element in that list against the first element of the other list. 
      - In this example: Left had the smaller value at index 0
      - Compare left[1] against right[0]
      - Whichever is smaller is now both[1];
      - Reminder that both lists need to be pre sorted.
      - Small correction here. The lists are all 1 element long, so the lists themselves don't iterate as if in a standard
      array. The comparisons are made between two arrays at maximum 1 element long. Both is a standard array of N length.
   + Time complexity:
      - Worst Case: O(n*log(n));
      - Best case: O(N);
   + Does not mutate the array since it creates a new array (Both)
   + Pseudo for merge sort:
   Base case
   function merge_sort(arr) {
      if (arr.length === 1) {
         return arr;
      }
   }
   middle_index = floor of int. of (left + right) / 2
   left_arr = arr from 0 to middle_index;
   right_arr = arr from middle_index to end;

   // recursive call
   mergeSort(leftArray);
   mergeSort(rightArray);
   // everything above will accomplish step one; split the array into single value arrays.

   // this will do the recursive splitting and the final merge at once
   return merge(mergeSort(leftArray), mergeSort(rightArray));

   function merge(leftArr, rightArr) {
      sortedArray = [];
      while (leftArr.length && rightArr.length > 0) {
         if (leftArr[0] < rightArr[0]) {
            sortedArray.push(leftArr[0]);
            remove leftArr[0] from leftArr;
         } else {
            sortedArray.push(rightArr[0]);
            remove rightArr[0] from rightArr;
         }
      }
      return sortedArray with concatenated leftArr + rightArr;
   }

// This will create an array of single element arrays, leftArray and rightArray, using recursion. 
   const mergeSort = (startArray) => {
  const length = startArray.length;
  if (length === 1) {
    return startArray;
  }
  
  const mid = Math.floor(length / 2);
  const leftArray = startArray.slice(0, mid);
  const rightArray = startArray.slice(mid, length);

  return merge(mergeSort(leftArray), mergeSort(rightArray))
}

// Once the recursion is complete, merge will compare each single element array and order each element into a new array
// It then deletes the first array in the outer array, "dropping" the next value to the head for comparison. 
// The concatenation at the end occurs because either array may not be empty, only one of them is needed to be empty for
// the program to return. In that case, the final array needs to be a composite of all arrays as below. 
const merge = (leftArray, rightArray) => {
  const sortedArray = [];
  while (leftArray.length > 0 && rightArray.length > 0) {
    if (leftArray[0] < rightArray[0]) {
      sortedArray.push(leftArray[0]);
      leftArray.shift();
    } else {
      sortedArray.push(rightArray[0]);
      rightArray.shift();
    }
  }
  return sortedArray.concat(leftArray).concat(rightArray);
}

- Quicksort
   + Divide and conquer 
   + recursive
   + Pivot = random value of the array 
   + Partition = create sub arrays based on lesser than / greater than the pivot value
   + Choose pivot from input array. 
     - Sub array of lesser than / greater than the pivot values. 
     - repeats until the sub arrays contain zero or 1 element. 
     - the LT is never compared to the GT group
   + Runtime of: O(N log(N))
   + Worst case runtime of: O(N^2) -- when the pivot is greatest or least value in the list each time
   + If the data set is already sorted, then it's often the worst case runtime.
   + Pseudo: 
   if (given_arr.length > 1) {
      find pivot index through partitioning
         if (left_pointer < pivot_index) {
            recursive call to quick_sort(given_array.slice(left_pointer, pivot_index));
         } else if (pivot_index < right_pointer) {
            recursive call to quick_sort(given_array.slice(right_pointer, pivot_index));
         }
   }

   Partitioning Pseudo:
   start with middle_index
   while you haven't looked through the whole array (leftIndex < rightIndex);
   move leftIndex up until you encounter value > pivot
   move rightIndex down until you encounter value < pivot
   swap those found elements
   return the last left element index
   
   + Pivot can be:
   First element of the array
   Last element of the array
   Middle element of the array
   Random element of the array

const swap = require('./swap');

const quicksort = (array, leftBound = 0, rightBound = array.length - 1) => {
  if (rightBound > leftBound) {
    const pivotIndex = partition(array, leftBound, rightBound);
    quicksort(array, leftBound, pivotIndex - 1);
    quicksort(array, pivotIndex, rightBound);
  }
  return array;
}

// Thinking in states. The outer while loop is a base case. There are two inner while loops that move past each element in the
// given array if it passes the comparision. Then a final if statement handles when neither element passes the test. 
// making the swap between smaller/larger elements in the given array. 
const partition = (array, leftIndex, rightIndex) => {
  const pivot = array[Math.floor((rightIndex + leftIndex) / 2)];
  while (leftIndex <= rightIndex) {
    while (array[leftIndex] < pivot) {
      leftIndex++;
    }
    while (array[rightIndex] > pivot) {
      rightIndex--;
    }
    if (leftIndex <= rightIndex) {
      swap(array, leftIndex, rightIndex);
      leftIndex++;
      rightIndex--;
    }
  }
  return leftIndex;
}

   const temp = arr[indexTwo];
   arr[indexTwo] = arr[indexOne];
   arr[indexOne] = temp;

- Heaps 
    + a binary tree with a maximum and minimum value.
    + min heap - the root is the minimum value of the dataset, every child value is greater than or equal to its parent
    + max heaps - the root is the maximum value of the dataset, every child value is less than or equal to its parent
    + max heaps and min heaps are considered separate structures
    + heapify up - when an element that breaks the fundamental rules of a given heap is passed up the tree, replacing it's parent,
    until the conditions of the tree are met. 
    + heapify down - when the least value is the topmost node, if we want to replace that node we heapify down. 
    take the bottom right node with no children and replace the root. Then shift the new root with the least value between 
    it's new children until the conditions of the tree are met. 
    + heaps are good for knowing the maximum and minimum of a dataset. 
    + often uses arrays under the hood

   class MinHeap {
  constructor() {
    this.heap = [ null ];
    this.size = 0;
  }

  popMin() {
    if (this.size === 0) {
      return null
    }
    console.log(`\n.. Swap ${this.heap[1]} with last element ${this.heap[this.size]}`);
    this.swap(1, this.size);
    const min = this.heap.pop();
    this.size--;
    console.log(`.. Removed ${min} from heap`);
    console.log('..',this.heap);
    this.heapify();
    return min;
  }

  add(value) {
    console.log(`.. adding ${value}`);
    this.heap.push(value);
    this.size++;
    this.bubbleUp();
    console.log(`added ${value} to heap`, this.heap);
  }

  bubbleUp() {
    let current = this.size;
    while (current > 1 && this.heap[getParent(current)] > this.heap[current]) {
      console.log(`.. swap ${this.heap[current]} with parent ${this.heap[getParent(current)]}`);
      this.swap(current, getParent(current));
      console.log('..', this.heap);
      current = getParent(current);
    }
  }

  heapify() {
    console.log('Heapify');
    let current = 1;
    let leftChild = getLeft(current);
    let rightChild = getRight(current);

    while (this.canSwap(current, leftChild, rightChild)) {
      if (this.exists(leftChild) && this.exists(rightChild)) {
        if (leftChild < rightChild) {
          this.swap(current, leftChild);
          current = getLeft(current);
        } else {
          this.swap(current, rightChild);
          current = getRight(current);
        }
      } else {
        this.swap(current, leftChild);
        current = getLeft(current);
      }
      leftChild = getLeft(current);
      rightChild = getRight(current);
    }
  }

  exists(index) {
    return index <= this.size;
  }

  canSwap(current, leftChild, rightChild) {
    // Check that one of the possible swap conditions exists
    return (
      this.exists(leftChild) && this.heap[current] > this.heap[leftChild]
      || this.exists(rightChild) && this.heap[current] > this.heap[rightChild]
    );
  }

  swap(a, b) {
    [this.heap[a], this.heap[b]] = [this.heap[b], this.heap[a]];
  }

}

const getParent = current => Math.floor((current / 2));
const getLeft = current => current * 2;
const getRight = current => current * 2 + 1;

- Binary Tree
    + has the following properties: 
    Data
    depth value - top level is 1, everything greater than 1 is lower in the tree
    left pointer - points to the left child of the tree, itself a binary tree, and must have data lesser than the root nodes data
    right pointer - points to right child of the tree, itself a binary tree, must have data greater than the root nodes data

    Three methods: Preorder, Inorder, Postorder. 
    Preorder - current node, left child node, then right child node
    Inorder - left child node, current node, right child node -- this will give you a sorted list of the tree values
    Postorder - left child node, right child node, current node

- asymptotic notation
   + Used to understand the total number of instructions a program will require. 
   + Theta, O, and Omega are used to represent N^2
