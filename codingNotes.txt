- asymptotic notation
   + Used to understand the total number of instructions a program will require. 
   + Theta, O, and Omega are used to represent N^2
   + Use the most dominant term in the formula, which means the most computationally significant. 
   + Big ol Theta: use when there is only has one case in terms of runtime
   function(n) 
      count = 0
      while N/2 !== 0;
         increment count
         N = N/2;
      return count
   Counting these iterations will give you Asymptotic notation.
   For the above pseudo code, you get Theta log2 N
   + Common runtimes: 
   0(1) - constant run
   0(log N) - logarithmic run
   0(N) - linear run
   0(N log N) - used in sorting
   0(N^2) - polynomial run time
   0(2^N) - exponential run time
   0(N!)  - factorial run time


- Recursion
   + calling a function or method from within itself. 
   + We've done this a few times, and watched several tutorials that used recursion for data structures. 
   + pseudo: 
   define the function, speller
      if there are no more letters // this is the "Base case" or an exit condition
         print all done
      print the first letter
      call speller with the given name - the first letter
   + compared to an iterative approach, you don't need a loop or to know the length of the target beforehand. 
   + recursion works via the call stack, a stack data structure that all of your functions get piled onto. 
   The last function you call is the first to be executed. 
   + pseudo:
   sum_list(arr) {
      if arr empty? 
      return 0;
      
      return first + sum_list(arr-1);
   }
   + example of a linked list method for finding matching node data recursively. 
  findNodeRecursively(data, currentNode = this.head) {
    if (currentNode === null) {
      return null;
    } else if (currentNode.data === data) {
      return currentNode;
    } else {
      return this.findNodeRecursively(data, currentNode.next);
    }
  }
