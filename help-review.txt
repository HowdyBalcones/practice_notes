++ Commands
ls - list directory contents
cd - move through directory hierarchy 
mkdir - make a new directory
rmdir - remove a directory
rm - remove files, -R for all files, handle with care
open - open a file, directory, program, etc
find - a powerful way to search and interact with files
grep - a very powerful way to search for files, contents of files, regex compatible
  + grep -i 
  + egrep -i 'search term'
  + 
sed - a line editor and filter program, regex compatible, quite handy
++ awk - a programming language for text, powerful and arcane
cp - copy a file at one point in file hierarchy to another point in the file hierarchy
++ rsync - copy many files to a directory, offers additional utility such as ignoring duplicates
cron - set commands, programs, scripts, etc to run on a schedule while the machine is active
crontab - view the existing cron commands in a table
head - view the top section of a file or output, default 10 lines
tail - view the bottom section of a file or output, default 10 lines
top - view many pieces of information about OS, Machine, current processes, imagine a text based Windows Task Manager but OG 
btop - an improved top with graphical overlay using ncurses lib
ps - view processes specifically, defaults to current commands running in the shell
kill - kill a process via multiple targets and signals
killall - kill multiple processes via multiple targets and signals 
stat - return info about file passed as argument, useful! Especially if you need to know things about a file in conditions. 
printf - print text to console, with lots of formatting options!
echo - output to console, with less formatting options!
print -

++ Shell syntax and command structures
  + declare variables - <varName>='string' <varName>=1234
  + environment variables - export PATH=$PATH:/custom/path
  + expand variables - $<varName>
  + parameter expansion 
	- <varName>=${givenCommands}
  + command Substitution - executes command in subshell and replaces command substitution with output, /n deleted
 	- $(command)	
  + arithmetic expansion - math
	- $(( expression ))
  + substring extraction
   	
  + declare functions 
	- functionName () {}
  + for in loop 
	- for <var> in "target"; do done
  + declare array 
	- <varName>=("item1" "item2" "item3")
	- echo "${<varName>[0]}" - print "item1"
	- echo "${<varName>[@]}" - 
  + declare associative array - typeset
	- typeset -A
  + positional parameters
	- ${1..9} 
  + special parameters
	- $# number of positional parameter
	- $@ all positional parameters (individually quoted)
	- $* all pos. params (single string)
	- $? exit status of the last command
	- $$ process id of the current shell
	- $! process id of the last background shell
	- $- current options set for the shell
	- $_ last argument of the previous shell
  + if statements
	- if [[ conditional boolean ]]; then
	  elif [[ second conditional ]]; then
	  fi
  + IFS - a list of characters that separate fields; used when the shell splits words as part of expansion
