++ Examples

+ magick montage
+ 1 -- create an array of input images as output image
magick montage doctor.png golf.png montage.png

+ 2 -- adjust the frame around the images with +2+2
magick montage doctor.png golf.png -geometry +2+2 montage.png

+ 3 -- resize each image to fit 48x48
magick montage doctor.png golf.png -geometry 48x48+2+2 montage.png

+ 4 -- resize only images larger than given size, escaped > sym
magick montage doctor.png golf.png -geometry 48x48\>+2+2 montage.png 

++ 5 -- this one is to our interest, we can overlap images
magick montage doctor.png golf.png -geometry 100x100-10-10 montage.png

+ 6 -- only resize smaller images 1x1\<
magick montage doctor.png golf.png -geometry 1x1\<+2+2 montage.png

+ 7 

+ magick identify -- if we need information about an image, use identify and store that info in memory. 
This allows for testing of images by a script for some purpose. 

+ 8 -- use identify to get the width and height only 
magick identify -format "%wx%h" montage.png

+ magick -crop
+ 9 
magick rose: -crop 40x30+10+10 output.gif

+ 10 -- this is how to avoid cropping without the canvas leftover 
magick rose: -crop 40x30+10+10 +repage output.gif
