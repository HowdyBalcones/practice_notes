    + Maintenance and How-To
        - finding ip and other stuff
            + ifconfig, ip a
            + sudo netstat -tuln 
                * this will show you connections on the host server
        - changing, updating, maintaining shells and environment for users
            + chsh -s, cat /etc/shells, echo $SHELL
            
            
        - adding users
        - removing users
        - user maintenance
            + passwd, /etc/passwd
        - using SSH
            + sudo apt update
            + sudo apt install openssh-server
            * Enable and Start the SSH service
            + sudo systemctl enable ssh
            + sudo systemctl start ssh 
            + sudo systemctl status ssh 
            * verify SSH is listening on port 22 (this port will change)
            + sudo netstat -tuln | grep 22
            * Basic server connection 
            + ssh username@server_ip ; EG ssh john@192.168.1.100
            * Hardening SSH
            + sudo vim /etc/ssh/sshd_config - disable root login
            * settings in sshd_config
            PermitRootLogin no
            Port 3328
            * apply changes to sshd_config
            + sudo systemctl restart ssh
            * connect to this port 3328
            + ssh username@server_ip -p 3328
            + ssh 23340-webster@192.168.1.164 -p XXXX            
            * Using ssh keys for more secure connection (rather than PW)
            + ssh-keygen -t rsa -b  
            * to end client connection
            + ssh exit

        - uploading and syncing files across ssh
